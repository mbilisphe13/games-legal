# Zerotal Games — legal pages

Privacy policies for the Android games, served as a static site by GitHub
Pages: <https://mbilisphe13.github.io/games-legal/>

This repository is public **only** because Google Play requires a privacy
policy at a URL reachable without a login, and GitHub Pages cannot serve from
a private repository on a free account. The game source stays private; nothing
here but these pages.

One page per game, so each app's listing points at its own URL and a policy can
be revised without touching the others:

| Game | Page |
| --- | --- |
| Blockwave | [`blockwave/privacy.html`](blockwave/privacy.html) |

When a policy changes, update its effective date in the same commit — the page
tells readers the revised version appears at that URL, so the date is the only
way anyone can tell it moved.
